# LabSafe 学习助手

这是一个用于兰州交通大学实验室安全教育平台的 Chrome / Edge 扩展。手动点击一次“开始学习”后，它会在当前标签页中识别未完成的必学和选学课程：视频可设为 1×–16×，安全手册等非视频资料按页面计时等待，达标后返回课程列表继续下一门。

扩展只操作顶层页面可见内容；若页面使用跨源 iframe、多个视频或无法唯一确认的控件，扩展会停止并提示需要处理。视频播放结束出现“视频已经播放完毕，请选择其他视频！”弹窗时，助手会自动点击其中的“确定”按钮再返回列表；无法安全确认弹窗按钮时会停止并提示。课程列表加载较慢时（表格尚未渲染），助手最多等待约 30 秒再继续，不会立即放弃。

## 安装到 Chrome 或 Edge

1. 将本项目保存到本机并解压（如果收到的是压缩包）。
2. 打开浏览器扩展管理页：Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 打开页面上的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目中的 `extension` 文件夹，而不是项目根文件夹。
5. 确认扩展列表中出现“LabSafe 学习助手”。如后续修改扩展文件，可在扩展管理页点击刷新图标重新加载。

## 使用

1. 在浏览器中打开并登录学习平台，进入 `https://labsafe.lzjtu.edu.cn/lab-study-front/` 下的学习页面；个人中心也可以作为起点。
2. 点击工具栏中的扩展图标。首次使用时，如图标未显示，可从扩展菜单中固定它。
3. 选择 1×–16× 的倍速，然后点击“开始学习”。倍速偏好会保存在浏览器本地；运行中修改倍速会应用到当前视频。非视频资料的计时不受倍速影响。
4. “暂停”会暂停本次自动操作；“继续”会重新检查当前页面；“停止”会清除当前标签页的学习会话。停止（或需要处理）之后再次点击“开始学习”，会建立新会话并重新拉起自动流程，无需刷新页面。
5. 页面显示的“已学习”达到“要求学习”时，助手会记为完成并返回列表，不要求视频触发结束事件。若视频已播完但计时不足、平台禁止重播，助手不会再循环播放；它会把该课列为本次未达标、先返回学习其他课程，最后提示人工检查。非视频资料只按页面可见计时判断。列表需能确认课程表头（名称/学习模块/学习进度/操作）、行内进度和“去学习”按钮，才会自动选择或翻页；列表页本身没有“未学/已学”筛选标签也可以工作。

题库练习课程会从课程列表中的“去学习”进入。助手识别“可练习题库”弹窗或题库卡片后，逐题练习：单选、判断题点击选项；多选题勾选后点击该题下方的“提交答案”。未知题首次会尝试一个选项，读取平台随后显示的“正确答案”，再保存题干、选项和正确答案。已记录的题目会优先使用已知答案。每题操作间隔约 1 秒；下一页、退出和返回控件无法唯一确认时会停止提示。

练习记录保存在浏览器本地。点击扩展面板的“导出练习题库”可下载 JSON 文件，供自己复习。开始新一轮学习会重置本轮已访问题库列表，不会清除已采集的题目。题库课程是否达标仍以平台课程列表显示的学习时长为准。正式考试和模拟考试页面不会自动作答。

平台如何统计有效学习时长由平台决定；高倍速播放可能不计入有效学习时间。课程总时长也可能延迟约 5 分钟更新。助手不伪造计时或完成记录，不将视频结束当作平台已认可进度。

## 导出和分享诊断

如果视频未识别、自动切换未发生或状态异常，在目标学习页打开扩展面板并点击“导出诊断”。浏览器会下载一个 JSON 文件。诊断包含视频和 frame 数量，以及少量候选控件的标签、角色、匹配文案、属性名称、可见性和启用状态；不包含 Cookie、表单值、页面正文或网络响应。

分享前请自行打开文件检查内容。若愿意协助适配，可将该 JSON 文件交给维护者，并说明浏览器、页面现象和复现步骤。不要分享账号、密码、Cookie、完整页面截图或其他个人信息。

## 常见问题

- **提示不在允许页面范围内：**确认地址使用 HTTPS，主机为 `labsafe.lzjtu.edu.cn`，路径以 `/lab-study-front/` 开头。启动和导出诊断都只能在该范围内进行。
- **未找到唯一可见视频：**确认视频课已加载且当前页面只有一个可见的视频。资料页无需视频，会按可见学习计时工作。
- **视频在 iframe 中：**首版只检查顶层页面，不会进入 frame。跨源 iframe 无法由此扩展访问；导出诊断可显示 frame 数量，需由维护者根据页面结构另行适配。
- **开始后没有播放：**浏览器可能阻止了自动播放并要求处理。按提示在页面上手动播放，再点击“开始学习”重试；也可检查浏览器是否静音、页面是否仍在加载。
- **没有自动切换课程：**若视频结束但计时不足，助手只会把它列为未达标，不会假报完成。若“返回”或“去学习”控件不唯一、页面结构不同、计时长时间不增长，助手会安全停止。可导出诊断供自愿分享。
- **导航后助手未继续：**本次会话只保留在手动启动的标签页和相同站点中。若浏览器重启、离开站点或页面结构无法识别，请重新点击“开始学习”。

版本 1.2.8 增加了跳转与返回的实际地址核对。若“返回”点击后页面没有切换，助手会提示需要处理；若返回期间出现可唯一确认的“请求错误”弹窗，会关闭弹窗并有限次重试返回。模块子课程完成后，目录中的整个模块仍保持待完成，直到模块页面自身的学习计时达标。

版本 1.2.9 增加了个人中心“去学习”入口和安全视频页（`/security/safetyVideo/课程编号/视频编号`）的识别。页面地址中的编号和查询参数可以变化；对于其他平台内地址，助手会结合可见课程表头、唯一视频、平台学习计时和返回控件判断页面类型，加载中最多等待约 30 秒。安全视频页以可见学习计时达标为完成条件，并使用其“返回”按钮继续课程列表。

版本 1.3.0 增加题库练习、正确答案本地采集和 JSON 导出。练习页面的题干与选项只在答题后保存到本机；扩展不读取平台内部接口。多选题的每题提交、反馈读取和翻页按用户提供的页面截图实现。题库结束、返回列表和整轮累计时长尚未在真实站点完成连续实测；若遇到提示，请保留页面并导出诊断供定位。

版本 1.3.1 修复了练习题号由页面样式生成时题目无法识别、选项内原生 input 不可见时无法点击的问题。练习页可兼容有无 iView 选项组的结构；遇到页面错误时，面板直接显示具体原因，诊断文件增加题目结构计数而不记录题干。

版本 1.3.2 修复多选题“提交答案”在勾选选项后才出现的时序问题：先勾选，等待该题的提交控件出现，再提交并读取正确答案。若页面加载中丢失了第一次勾选，助手只在确认该选项仍未勾选时有限次重试；等待超时会提示具体原因，不会无限重复操作。

版本 1.3.3 支持判断题的“对 / 错”选项与平台显示的“正确答案：对 / 错”。揭示答案后会保存到本地题库，并继续处理后续题目。

版本 1.3.4 将选学课程纳入自动学习范围。助手仍按列表顺序选择未完成课程，并在模块页计时停滞时识别可见的选学子课；已完成课程继续跳过。

## 安全范围

扩展只在题库练习页面作答并记录平台显示的正确答案；不会回答正式或模拟考试、点击考试提交或完成控件、调用平台内部接口、伪造播放事件或篡改学习进度。自动选择仅作用于可确认的学习课程，不会猜测点击。
