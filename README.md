# LabSafe 学习助手

这是一个用于兰州交通大学实验室安全教育平台的 Chrome / Edge 扩展。手动点击一次“开始学习”后，它会在当前标签页中识别未完成的必学和选学课程：视频可设为 1×–16×，安全手册等非视频资料按页面计时等待，达标后返回课程列表继续下一门。

扩展只操作顶层页面可见内容；若页面使用跨源 iframe、多个视频或无法唯一确认的控件，扩展会停止并提示需要处理。视频播放结束出现“视频已经播放完毕，请选择其他视频！”弹窗时，助手会自动点击其中的“确定”按钮再返回列表；无法安全确认弹窗按钮时会停止并提示。课程列表加载较慢时（表格尚未渲染），助手最多等待约 30 秒再继续，不会立即放弃。

## 安装到 Chrome 或 Edge

1. 将本项目保存到本机并解压（如果收到的是压缩包）。
2. 打开浏览器扩展管理页：Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 打开页面上的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目中的 `extension` 文件夹，而不是项目根文件夹。
5. 确认扩展列表中出现“LabSafe 学习助手”。如后续修改扩展文件，可在扩展管理页点击刷新图标重新加载。

## 使用

1. 在浏览器中打开并登录学习平台，进入 `https://labsafe.lzjtu.edu.cn/lab-study-front/` 下的学习页面；个人中心也可以作为起点。
2. 点击工具栏中的扩展图标。首次使用时，如图标未显示，可从扩展菜单中固定它。
3. 选择 1×–16× 的倍速，然后点击“开始学习”。倍速偏好会保存在浏览器本地；运行中修改倍速会应用到当前视频。非视频资料的计时不受倍速影响。
4. “暂停”会暂停本次自动操作；“继续”会重新检查当前页面；“停止”会清除当前标签页的学习会话。停止（或需要处理）之后再次点击“开始学习”，会建立新会话并重新拉起自动流程，无需刷新页面。
5. 页面显示的“已学习”达到“要求学习”时，助手会记为完成并返回列表，不要求视频触发结束事件。若视频已播完但计时不足、平台禁止重播，助手不会再循环播放；它会把该课列为本次未达标、先返回学习其他课程，最后提示人工检查。非视频资料只按页面可见计时判断。列表需能确认课程表头（名称/学习模块/学习进度/操作）、行内进度和“去学习”按钮，才会自动选择或翻页；列表页本身没有“未学/已学”筛选标签也可以工作。

题库练习课程会从课程列表中的“去学习”进入。助手识别“可练习题库”弹窗或题库卡片后，逐个题库、逐页练习：单选、判断题点击选项；多选题逐项勾选并核对状态，全部目标选项选中后才点击该题下方的“提交答案”。未知题首次会尝试一个选项，读取平台随后显示的“正确答案”，再保存题干、选项和正确答案。已记录的题目会优先使用已知答案。每个勾选动作间隔约 1 秒；当前页全部揭示答案后，若“下一页”连续 5 次点击没有带来新题，则按当前题库结束处理，返回选择下一题库。退出和返回控件无法唯一确认时会停止提示。

练习记录保存在浏览器本地。点击扩展面板的“导出练习题库”可下载 JSON 文件，供自己复习。扩展面板会显示本轮已遍历题库数和下一题库；平台弹窗本身不显示这些标记。“开始学习”会保留本轮题库遍历进度，适合中断后接着学；要从第一个题库重来，先点击“清除本轮题库进度”，再点击“开始学习”。清除操作会停止当前自动流程，并只清除题库遍历状态，不删除已采集的题目答案。题库没有逐库时长要求：全部题库走完后，助手会留在最后一个练习页，按进入题库课程时列表显示的剩余时长加上进度更新缓冲时间等待，再返回列表核对。若平台仍显示欠时，会回到练习页继续等待并定期核对；只有列表显示整体时长达标，才继续下一项未完成任务。正式考试和模拟考试页面不会自动作答。

平台如何统计有效学习时长由平台决定；高倍速播放可能不计入有效学习时间。课程总时长也可能延迟约 5 分钟更新。助手不伪造计时或完成记录，不将视频结束当作平台已认可进度。

## 导出和分享诊断

如果视频未识别、自动切换未发生或状态异常，在目标学习页打开扩展面板并点击“导出诊断”。浏览器会下载一个 JSON 文件。诊断包含视频和 frame 数量，以及少量候选控件的标签、角色、匹配文案、属性名称、可见性和启用状态；不包含 Cookie、表单值、页面正文或网络响应。

分享前请自行打开文件检查内容。若愿意协助适配，可将该 JSON 文件交给维护者，并说明浏览器、页面现象和复现步骤。不要分享账号、密码、Cookie、完整页面截图或其他个人信息。

## 常见问题

- **提示不在允许页面范围内：**确认地址使用 HTTPS，主机为 `labsafe.lzjtu.edu.cn`，路径以 `/lab-study-front/` 开头。启动和导出诊断都只能在该范围内进行。
- **未找到唯一可见视频：**确认视频课已加载且当前页面只有一个可见的视频。资料页无需视频，会按可见学习计时工作。
- **视频在 iframe 中：**首版只检查顶层页面，不会进入 frame。跨源 iframe 无法由此扩展访问；导出诊断可显示 frame 数量，需由维护者根据页面结构另行适配。
- **开始后没有播放：**浏览器可能阻止了自动播放并要求处理。按提示在页面上手动播放，再点击“开始学习”重试；也可检查浏览器是否静音、页面是否仍在加载。
- **没有自动切换课程：**若视频结束但计时不足，助手只会把它列为未达标，不会假报完成。若“返回”或“去学习”控件不唯一、页面结构不同、计时长时间不增长，助手会安全停止。可导出诊断供自愿分享。
- **导航后助手未继续：**本次会话只保留在手动启动的标签页和相同站点中。若浏览器重启、离开站点或页面结构无法识别，请重新点击“开始学习”。

版本 1.3.0 增加题库练习、正确答案本地采集和 JSON 导出。练习页面的题干与选项只在答题后保存到本机；扩展不读取平台内部接口。多选题的每题提交、反馈读取和翻页按用户提供的页面截图实现。题库结束、返回列表和整轮累计时长尚未在真实站点完成连续实测；若遇到提示，请保留页面并导出诊断供定位。

版本 1.3.1 修复了练习题号由页面样式生成时题目无法识别、选项内原生 input 不可见时无法点击的问题。练习页可兼容有无 iView 选项组的结构；遇到页面错误时，面板直接显示具体原因，诊断文件增加题目结构计数而不记录题干。

版本 1.3.2 修复多选题“提交答案”在勾选选项后才出现的时序问题：先勾选，等待该题的提交控件出现，再提交并读取正确答案。若页面加载中丢失了第一次勾选，助手只在确认该选项仍未勾选时有限次重试；等待超时会提示具体原因，不会无限重复操作。

版本 1.3.3 支持判断题的“对 / 错”选项与平台显示的“正确答案：对 / 错”。揭示答案后会保存到本地题库，并继续处理后续题目。

版本 1.3.4 将选学课程纳入自动学习范围。助手仍按列表顺序选择未完成课程，并在模块页计时停滞时识别可见的选学子课；已完成课程继续跳过。

版本 1.3.5 修复题库末页“下一页”点击无变化时停止的问题；按题库顺序采集完各库后，在练习页等待整体课程时长，并回列表核对是否真正达标。题库遍历状态在本轮学习内保留，打开题库时不再提前标记为已完成。

版本 1.3.6 修复已收录多选题重做时可能只留下最后一个勾选项的问题。助手改为逐项点击、每次重新读取页面勾选状态，确认所有应选项都已选且无多余选项后才提交；无法确认时停止并提示。

版本 1.3.7 修复重复点击“开始学习”会清空题库遍历进度、反复从第一题库开始的问题。面板新增本轮题库进度显示和“清除本轮题库进度”按钮；需要重新遍历全部题库时手动清除，已采集的题目答案保留。

版本 1.3.9 扩展资料课“返回”控件识别：兼容箭头图标与“返回”文字组合、图标字体前缀及无按钮语义的文本节点；仍要求恰好一个可见可用的目标。诊断文件补充返回候选控件的结构信息，便于站点结构继续变化时定位。

版本 1.3.10 修复选学资料页顶部和底部各有一个同型“返回”按钮时误判歧义的问题。仅在多个候选均为同型、同文字的 iView 返回按钮时选择页面中的第一个；不同类型的多个返回入口仍停止提示。

版本 1.3.11 修复题库退出后返回课程列表时，后台短暂无法查询标签页就立即中断选课的问题。后台优先核对浏览器提供的消息发送页面地址；暂时无法确认时最多重试两次，未确认前不会点击“去学习”。会话丢失、暂停或页面离站会显示具体原因。更新扩展后请在扩展管理页点“重新加载”，再点击“开始学习”。

版本 1.3.12 根据新的故障诊断修复目录表格可见却被判为“长时间未出现”的问题：识别时排除页面残留的隐藏表格，只在唯一可见的表格中选课。页面跳转期间若后台暂时无法读取标签页，不再因此清除学习会话；课程完成、待处理和模块进入的确认也使用浏览器提供的页面来源。诊断新增目录表头、表体和可选课程数量，便于继续定位站点变化。更新后须重新加载扩展。

版本 1.3.13 为目录选课增加一次自动恢复：若后台会话意外丢失，先恢复本轮会话与课程进度，再重新确认选课，未确认前不点击课程。主动“停止”、真正离开学习站点或全部完成后不会自动恢复。页面导航只在最终地址确认离站后清除会话；需要人工处理的状态会暂停并保留进度。每轮学习有独立标识，旧页面的迟到消息不能停止新一轮。诊断新增后台会话状态、可恢复状态和最近一次会话事件，不记录课程或题目正文。

版本 1.3.14 针对页面控件出现后跳转仍延迟的情况，将课程切换与返回等待延长到约 60 秒。自动流程报错后等待 5 秒重新启动并保留本轮学习进度；同一课程连续 5 次仍失败则停下显示原始原因，手动“暂停”或“停止”会取消自动恢复。诊断记录首次暂停原因，避免后续只显示“后台学习会话已暂停”。更新扩展后请在扩展管理页点击“重新加载”，并手动点击一次“开始学习”。

版本 1.3.15 降低课程列表页的页面变化处理频率。旧版对列表中的每次元素变化都重新扫描整张课程表；其他浏览器环境或扩展若持续改动页面，可能造成“学习中”但页面卡顿。新版把短时间内的变化合并为一次检查，开始学习和返回目录仍会正常继续。更新后请在 Edge 扩展管理页点击“重新加载”。

版本 1.3.16 增加电脑保活：自动学习运行期间阻止系统因闲置休眠，屏幕仍可按系统设置关闭；暂停、停止、完成、离开学习站点或所有标签页都不再学习时释放保活。后台重新启动后会从保存的学习会话恢复保活。需要新增的浏览器 `power` 权限，更新后请重新加载扩展并确认权限。

版本 1.3.17 修复资料学习页计时短暂停滞时误把侧栏课程当作模块子课程并切换的问题。已确认是计时增长的资料页会继续等待；模块页仍按顺序进入子课程。诊断增加资料页计时停滞与模块父子状态，便于排查反复出现的“请求错误”。更新后请重新加载扩展；平台时长仍以页面实际显示为准。

版本 1.3.18 增加异常跳转保护：学习途中若平台将页面送回个人中心，或 10 秒内在目录与课程页之间切换 8 次，助手会暂停自动点击并保留本轮进度。此类情况不会按普通错误每 5 秒自动重试，避免持续触发平台请求；检查页面后可手动点击“继续”。诊断增加最近 10 秒路由变化次数，不记录课程名称或网页正文。

## 安全范围

扩展只在题库练习页面作答并记录平台显示的正确答案；不会回答正式或模拟考试、点击考试提交或完成控件、调用平台内部接口、伪造播放事件或篡改学习进度。自动选择仅作用于可确认的学习课程，不会猜测点击。
